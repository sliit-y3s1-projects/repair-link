# RepairLink

## Project Overview

**RepairLink** is a digital platform that connects:

- Consumers who need products repaired
- Technicians who provide repair services
- Spare-part sellers who provide replacement parts

The goal is to make repairing products easier, more trustworthy, and more accessible in Sri Lanka.

---

## Problem We Solve

Many people replace products that could still be repaired because:

- It is difficult to find trusted technicians
- Skilled technicians have limited online visibility
- Spare parts are difficult to find
- Consumers do not know who provides the right repair service
- There is no simple platform connecting consumers, technicians, and spare-part sellers

This leads to unnecessary spending, more electronic waste, and lost business opportunities for local technicians.

---

## Proposed Solution

RepairLink creates one ecosystem where:

**Consumer → finds Technician → Technician identifies repair needs → Spare-Part Seller provides required parts**

Instead of searching separately for technicians and spare parts, users can access everything through one platform.

---

# Main Features

## Consumer Features

- Browse technicians
- Search technicians by skill or product category
- Filter technicians by location and rating
- View technician profiles
- Submit a repair request
- Browse available spare parts
- Search and filter spare parts
- View technician and seller locations on a map

---

## Technician Features

- Create/view technician profile
- Add specialization and skills
- View repair requests
- View customer problem details
- Accept or respond to repair requests
- Search spare parts required for repairs

---

## Seller Features

- Add spare-part listings
- Add price, condition, location, and availability
- View listed spare parts
- Make parts searchable by consumers and technicians

---

## Map Integration

The platform can include a map to show:

- Nearby technicians
- Nearby spare-part sellers
- Technician/service locations

Possible implementation:

- **Leaflet**
- **OpenStreetMap**

---

The main priority is to complete these features first:

1. Landing page
2. Technician listing
3. Search and filter technicians
4. Create repair request form
5. Input validation
6. Repair request listing
7. Spare-part marketplace
8. Search/filter spare parts
9. Responsive mobile/desktop UI

---

## Example User Flow

A user has a broken laptop.

1. Opens RepairLink
2. Searches for **Laptop Repair**
3. Finds a suitable technician
4. Submits a repair request
5. Technician views the request
6. Technician searches for the required replacement part
7. Platform displays available spare-part sellers
